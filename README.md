# GREP 

## features:
1. The GREP refers to the command line utility used to search specific words, phrases or patterns in a text file.
2. The GREP stands for Global Regular Expression Print

### First Addition:
1. Making it into a simple file finder and reader
2. This requires using function to : take name of the file, read the file

### Second Addition:
1. applying command line utility using sys module
2. Adding word/phrase/pattern check feature using 'in' operator
3. Included absolute/relative path checker and corrector incase sys.argv splits the path due to whitespace in a name
